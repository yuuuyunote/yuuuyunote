## About

Discordサーバー運営・bot構成・セキュリティに関する情報を扱う日本語コミュニティ「**Guide Base +**」を個人運営。並行して note にて技術記事を発信し、年間10万PV超のリーチを持つ。コミュニティ・ツール・記事群を一貫した設計思想のもとで運用している。
